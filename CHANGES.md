## Rig checker rebuilt on measured data (2026-10-31)

Replaced the hand-set scores with Blender Open Data medians, generated by `tests/build-hardware.py` into `data/hardware.js`. The list grew from 4 CPUs and 8 GPUs to 177 CPUs and 159 GPUs, grouped by generation.

Corrections, checked against https://www.blender.org/download/requirements/ and https://docs.blender.org/manual/en/5.2/render/cycles/gpu_rendering.html:

- RX 580 no longer claims Cycles GPU rendering. HIP needs RDNA1 or newer (RX 5000 and up).
- Integrated Radeon Vega no longer sits with supported parts. Newer Radeon integrated graphics now use HIP.
- Added Intel Arc with oneAPI, which was missing.
- Hardware ray tracing now follows the manual: RTX, RX 6000 and newer, Arc, and Apple M3 and newer. The Apple M3 line is taken from Open Data results, not the manual.
- Parts below the 5.2 minimum now point to Blender 4.5 LTS.
- The Apple GPU now uses shared system memory instead of a fixed 16 GB.
- RAM guidance follows Blender's numbers: 8 GB minimum, 32 GB recommended.
- Removed the polygon-count estimates, which had no source.

The overall score is still our own estimate. It uses GPU 45%, CPU 30% and RAM 25%, and the weakest part holds it back.
